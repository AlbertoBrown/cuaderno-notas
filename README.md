# Cuaderno Notas

Aplicación web de apuntes diarios para registrar incidencias, errores de sondas, diferencias de carga y observaciones de los depósitos.

## Características
- Notas organizadas por día.
- Prompt del día para preparar consultas o análisis.
- Editor de apuntes con guardado automático en `localStorage`.
- Etiquetas: Errores, Prompt, Apuntes e Incidencias.
- Diseño responsive inspirado en una app de notas móvil.
- Instalación como PWA.

Abre `index.html` o publica el repositorio con GitHub Pages.
